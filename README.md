# Angular Signals Learning

A small, interactive course for learning Angular Signals inside VS Code.

## Run the extension

1. Run `npm install` in this folder.
2. Open the folder in VS Code.
3. Press `F5` to launch the Extension Development Host.
4. Run **Angular Signals: Start Learning** from the Command Palette.

Your current lesson and completed lessons are saved in the webview. The course covers writable signals, updating state, computed values, effects, and reading signals in templates.
